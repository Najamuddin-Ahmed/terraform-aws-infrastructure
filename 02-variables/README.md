# Terraform Variables

This mini-project demonstrates how to use input variables in Terraform to make infrastructure configuration more flexible and reusable.

## What I Learned

- How to declare Terraform variables
- How to define variable types
- How to assign default values
- How to use variables inside resources
- How to provide values using `terraform.tfvars`
- How to override default variable values
- How explicit variable values take precedence over default values
